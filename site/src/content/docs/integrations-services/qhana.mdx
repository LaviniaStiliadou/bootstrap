## QHAna

QHAna is a platform used by Qonstruct to provide implementations for **QML elements**.

Qonstruct provides several QML elements that represent quantum machine learning and related computational operations. Instead of implementing the execution logic directly inside Qonstruct, these elements are implemented as **QHAna plugins**.

During workflow execution, the workflow engine calls the corresponding QHAna plugins whenever a workflow contains a QML element that requires execution.

## QML Elements as Plugins

QML and ML elements in Qonstruct describe operations at the modeling level. Their concrete execution is provided by QHAna plugins.

A QML element can therefore be understood as an executable modeling component:

```text
QML Element
     │
     ▼
QHAna Plugin
     │
     ▼
Execution
     │
     ▼
Result
```

## QHAna During Workflow Execution

When a Qonstruct model is transformed into a quantum workflow, QML elements are identified during the transformation process. During execution, the workflow engine invokes the corresponding QHAna plugins.

The plugin receives the required inputs and metadata, performs its operation, and returns the result to the workflow.
