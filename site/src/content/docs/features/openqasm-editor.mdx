## Overview

The OpenQASM editor is a text view of the modeled circuit. It works in both directions: it shows the OpenQASM code generated from the model, and it turns OpenQASM code that you enter into a model on the canvas.

## Enabling the editor

The editor is off by default. To turn it on:

1. Open the **Experience Mode** panel in the top-left corner of the canvas.
2. Set **QASM Editor** to *On*.

The **QASM** tab then appears in the panel on the right, next to **Properties** and **Math Mode**.

## From model to code

Click **Refresh** in the QASM tab. The current model is sent to the backend, compiled, and the generated OpenQASM code is shown in the editor.

## From code to model

1. Enter or paste OpenQASM 2 or OpenQASM 3 code into the editor.
2. Click **Apply to Canvas**.

The code is parsed in the browser, without a backend call, and the corresponding model is created on the canvas: a **Qubit Circuit** node for each declared qubit and a gate node for each gate, connected in the order of the code.

```openqasm
OPENQASM 3.0;
include "stdgates.inc";

qubit[2] q;
h q[0];
cx q[0], q[1];
```

### Supported statements

| Statement                                                | Result                         |
| -------------------------------------------------------- | ------------------------------ |
| `qubit[n] name;` (OpenQASM 3), `qreg name[n];` (OpenQASM 2) | One qubit node per qubit     |
| `h`, `x`, `y`, `z`, `s`, `t`, `sdg`, `tdg`, `id`          | Single-qubit gates            |
| `rx`, `ry`, `rz`, `p`, `u1`, `u2`, `u3`                  | Parameterized single-qubit gates |
| `cx` (`cnot`), `cy`, `cz`, `ch`, `swap`                  | Two-qubit gates               |
| `crx`, `cry`, `crz`, `cp`                                | Parameterized two-qubit gates |
| `ccx`, `cswap`                                           | Toffoli and CSWAP             |

Header lines (`OPENQASM`, `include`), classical registers (`creg`, `bit`), `measure` and `barrier` are skipped. Custom `gate` definitions, `if` statements and aliases (`let`) aren't converted.

## Explicit updates

Changes aren't transferred while you type. Both directions run only when you click **Refresh** or **Apply to Canvas**. This avoids continuous translation calls while you edit and makes it clear when a change was applied.

## Opening an OpenQASM file

To load an OpenQASM file from disk, open the **Open Diagram** menu in the toolbar, choose **Open OpenQASM** and select the file. The file is converted into a model on the canvas.
