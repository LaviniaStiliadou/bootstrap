## Overview

The **Canvas** is the main workspace in Qonstruct where users create and edit their models. Modeling elements can be placed on the canvas, connected, configured, and organized to build quantum and hybrid quantum-classical applications.

The canvas provides several features to support modeling, navigation, and customization.

## Grid

The canvas provides a **grid** that helps users align and organize modeling elements.

The grid provides a visual reference when placing elements and makes it easier to create structured models.

## Zoom

The canvas supports **zooming** to adjust the level of detail shown in the workspace.

Users can:

* **Zoom in** to work with individual modeling elements in more detail.
* **Zoom out** to get an overview of larger models.

This allows users to switch between detailed editing and an overview of the complete model.

## Grouping elements

Modeling elements can be **grouped** to organize related parts of a model.

Grouping allows several elements to be treated as a logical unit, making larger models easier to organize and navigate.

## Experience Model Panel

The canvas contains the **Experience Model Panel**, which provides settings for adapting the modeling experience to the user's needs.

### Explorer and Pioneer

The Experience Model Panel allows users to switch between two modeling experiences:

* **Explorer** — provides a more guided modeling experience with a higher level of abstraction.
* **Pioneer** — provides access to more advanced modeling capabilities and lower-level details.

The selected experience determines which modeling capabilities are presented to the user.

### Compact mode

The **Compact** setting controls how much information is displayed in the modeling interface.

When enabled, the interface uses a more compact presentation, allowing more of the model to remain visible on the canvas.

### Math mode

The **Math mode** setting controls whether mathematical representations are used within the modeling experience.

Users can turn Math mode **on or off** depending on whether they want to work with mathematical representations in the interface.

### OpenQASM editor

The Experience Model Panel also provides an option to enable or disable the **OpenQASM editor**.

When enabled, users can access the OpenQASM representation of the quantum model directly within Qonstruct. This provides a lower-level view for users who want to inspect or work with the generated quantum code.

## Canvas settings overview

| Setting                | Description                                                                  |
| ---------------------- | ---------------------------------------------------------------------------- |
| **Grid**               | Provides a visual grid for aligning and organizing modeling elements.        |
| **Zoom in / Zoom out** | Adjusts the level of detail displayed on the canvas.                         |
| **Grouping**           | Organizes multiple modeling elements into a logical group.                   |
| **Explorer / Pioneer** | Switches between the available modeling experiences.                         |
| **Compact**            | Enables or disables the compact presentation of the modeling interface.      |
| **Math mode**          | Enables or disables mathematical representations in the modeling experience. |
| **OpenQASM editor**    | Enables or disables access to the OpenQASM editor.                           |
