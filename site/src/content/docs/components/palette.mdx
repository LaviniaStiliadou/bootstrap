## Overview

The Palette contains the modeling elements available in Qonstruct. It provides a central place where users can browse the elements of the [modeling language](../modeling-language) and add them to their model.

The available modeling elements are organized in the palette according to their respective categories. This allows users to discover elements based on their purpose, such as data types, boundary elements, operators, control flow, circuit primitives, and algorithm elements.

## Search

The palette provides a **search function** to quickly find a specific modeling element.

As you enter a search term, the palette filters the available modeling elements and displays the matching results. This makes it easier to find an element without having to browse through all available categories.

For example, searching for `measurement` displays the corresponding **Measurement** modeling element.

## Adding an element

Once a matching modeling element has been found, it can be added to the canvas directly from the search.

After entering a search term, press **Enter** to add the first matching modeling element to the canvas. This provides a quick way to create models without manually dragging an element from the palette.

The basic interaction is therefore:

1. Open or focus the palette search.
2. Enter the name of the desired modeling element.
3. Review the matching elements.
4. Press **Enter** to add the first matching element to the canvas.

The element is then placed on the canvas and can be configured through its available properties.
