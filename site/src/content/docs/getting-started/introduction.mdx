## Basic setup

The basic setup provides everything you need to create quantum application models and execute them as quantum circuits or workflows.

### Prerequisites

Before you begin, make sure you have:

* Node.js 22.x or later
* pnpm
* Docker and Docker Compose

### 1. Start the required services

Clone and start the LEQO backend:

```bash
git clone https://github.com/LEQO-Framework/leqo-backend
cd leqo-backend
docker compose -f compose-dev.yaml up -d
```

The backend runs on port `8000`.

### 2. Configure Qonstruct

Create a `.env` file in the Qonstruct project root:

```env
VITE_LOW_CODE_BACKEND=http://localhost:8000
```

### 3. Start Qonstruct

Install the dependencies and start the development server:

```bash
pnpm install
npm run dev
```

Qonstruct runs on port `4242`.

### 4. Open Qonstruct

Open https://low-code-modeler.lavinia-stiliadou.workers.dev? in your browser.

You can now create quantum application models and execute them as quantum circuits or workflows.
