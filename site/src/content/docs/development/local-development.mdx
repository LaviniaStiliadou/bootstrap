## Local development

The Qonstruct modeler can be run locally for development and testing. Before getting started, make sure you have [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/) installed.

Clone the [Qonstruct repository](https://github.com/LEQO-Framework/low-code-modeler) and install the project dependencies:

```bash
pnpm install
```

Once the dependencies have been installed, start the modeler locally with:

```bash
npm run dev
```

The development server will provide a local URL where you can open and test the modeler.

## Linting

Qonstruct uses [Oxlint](https://oxc.rs/docs/guide/usage/linter) for static analysis of the codebase.

Oxlint is included as a development dependency and is installed automatically when installing the project dependencies. Run it with:

```bash
pnpm exec oxlint .
```

Alternatively, if you are using npm:

```bash
pnpm install
npx oxlint .
```

The linting configuration is defined in `oxlint.config.ts`.

Oxlint is also run automatically in GitHub Actions for pull requests targeting `main`. Running the linter locally before opening a pull request helps ensure that your changes pass the project's automated checks.
