## Overview

The Qonstruct repository contains the source code, documentation, backend components, and supporting files required to develop and run the Qonstruct modeler.

The main parts of the repository are:

| Directory / File       | Description                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| `.github/workflows`    | Contains GitHub Actions workflows used for automated tasks such as linting and continuous integration. |
| `backend`              | Contains backend components used by the Qonstruct project.                                             |
| `docs`                 | Contains the Qonstruct documentation.                                                                  |
| `public`               | Contains static assets that are served by the application.                                             |
| `src`                  | Contains the main source code of the Qonstruct modeler.                                                |
| `THIRD_PARTY_LICENSES` | Contains license information for third-party dependencies used by the project.                         |

## Source code

The `src` directory contains the main implementation of the Qonstruct modeler. This is where the user interface, modeling functionality, and other application logic are developed.

Changes to the modeler's functionality will generally be made within this directory.

## Documentation

The `docs` directory contains the documentation for Qonstruct.

It includes documentation pages covering topics such as the modeling language, canvas, palette, properties panel, toolbar, and development workflow.

## Backend

The `backend` directory contains backend-related components of the project.

These components support functionality that is not executed directly in the modeler's frontend.

## Public assets

The `public` directory contains static assets used by the application. These files can be referenced directly by the application without being processed as source code.

## GitHub workflows

The `.github/workflows` directory contains the GitHub Actions workflows used by the project.

These workflows automate tasks such as checking changes and running project validation when changes are submitted.

## Third-party licenses

The `THIRD_PARTY_LICENSES` file contains license information for third-party software and dependencies used by Qonstruct.

When adding or updating dependencies, their licensing information should be considered as part of the project.
