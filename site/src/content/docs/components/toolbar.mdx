## How it works
### Toolbar

The toolbar provides commands for managing models and communicating with execution services, including:

* **New Diagram**
* **Open**
* **Save**
* **Save As**
* **Upload**
* **Configuration**
* **Send to Backend**
* **Send to Qunicorn**
