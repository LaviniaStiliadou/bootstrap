## Overview

The Math Mode links the visual circuit to its underlying mathematical description. It shows the state that the modeled circuit produces, how each gate changes it, and the resulting measurement probabilities.

## Enabling the Math Mode

The Math Mode is off by default. To turn it on:

1. Open the **Experience Mode** panel in the top-left corner of the canvas.
2. Set **Math Mode** to *On*.

The **Math Mode** tab then appears in the panel on the right, next to **Properties** and **QASM**.

![Enabling the Math Mode in the Experience Mode panel](https://raw.githubusercontent.com/LaviniaStiliadou/bootstrap/main/images/experience_mode.png)

## Refreshing the representations

The Math Mode doesn't update while you edit. Click **Refresh** to send the current model to the backend and recalculate all representations.

## Representations

| View         | Shows                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| **Dirac**    | The resulting quantum state of the circuit in Dirac notation.                                                                  |
| **Steps**    | The intermediate states. For every gate, the resulting state vector is shown as its own derivation step, with the applied operation. |
| **Histogram**| The measurement probabilities of the resulting state.                                                                          |
| **Bloch**    | The state of a single qubit as an interactive 3D Bloch sphere that you can rotate with the mouse. For circuits with several qubits, select the qubit to display. |
| **Properties** | Whether the current state is entangled.                                                                                      |

## Linking steps and circuit elements

Every step in the **Steps** view is linked to the circuit element it comes from. When you select a step, the canvas highlights all nodes that contributed to the state up to and including this step, so you see the complete derivation path rather than only the gate of that step.

- The highlighting is temporary and disappears automatically.
- If a highlighted node is inside a group, only that node is highlighted, not the group.

## AI explanation

The **Explain** button generates a natural-language explanation of how the state evolves. It is based on the initial state, the applied operations and the individual state changes, and is shown below the derivation steps.

The explanation uses the Mistral API. Set the API token as `VITE_MISTRAL_TOKEN` in the `.env` file before starting the modeler (see [Configuration](./configuration)). The Explain button reads the token from the environment, not from the configuration dialog.

## Exporting

The **Export** and **Export all** buttons provide these formats:

| Export                     | Content                                                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Copy as LaTeX or Unicode   | Copies the Dirac notation as LaTeX source or as Unicode text.                                                                   |
| `main.tex`                 | A complete LaTeX document that compiles in Overleaf without changes: package imports, derivation steps, matrix definitions and a table of measurement probabilities. It already includes the separately exported `circuit.png`. |
| `dirac_export.zip`         | The mathematical representations together with the normalized `circuit.qasm` and a JSON representation of the circuit.         |

## Limitations

- The Math Mode calculates state vectors, so it is intended for small circuits. The number of amplitudes doubles with every qubit.
- The representations reflect the model at the time of the last **Refresh**.
