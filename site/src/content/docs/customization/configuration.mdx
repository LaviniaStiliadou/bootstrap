## Overview

Qonstruct is configured in two places:

- **Environment variables** in the `.env` file set the defaults when the modeler starts.
- The **Configuration** dialog (gear icon in the toolbar) changes most settings while the modeler is running.

Changes in the dialog apply to the current browser session. Only the automatic connection settings are kept after a reload; all other settings fall back to the values from `.env`.

## Environment variables

Create a `.env` file in the root of the repository. Vite reads it at startup, so restart the dev server (`pnpm dev`) after changing it. Only variables starting with `VITE_` are available in the browser.

### Services

| Variable                    | Default                                   | Used for                                                                  |
| --------------------------- | ----------------------------------------- | ------------------------------------------------------------------------- |
| `VITE_LOW_CODE_BACKEND`     | `http://localhost:8000`                   | LEQO backend: compiling models into OpenQASM, Math Mode, QASM editor.     |
| `VITE_QUNICORN`             | `http://localhost:8080`                   | Qunicorn: executing the compiled circuits.                                |
| `VITE_NISQ_ANALYZER`        | `http://localhost:8098/nisq-analyzer`     | NISQ Analyzer: selecting implementations and quantum devices.             |
| `VITE_CAMUNDA7_ENDPOINT`    | `http://localhost:8090/engine-rest`       | Camunda 7: deploying and running generated workflows.                     |
| `VITE_PATTERN_ATLAS_UI`     | `http://localhost:1978`                   | Pattern Atlas UI: browsing patterns.                                      |
| `VITE_PATTERN_ATLAS_API`    | `http://localhost:1977/patternatlas/patternLanguages/af7780d5-1f97-4536-8da7-4194b093ab1d` | Pattern Atlas API: the pattern language used for pattern selection. |
| `VITE_QC_ATLAS`             | `http://localhost:6626`                   | QC Atlas: pattern implementations.                                        |
| `VITE_DOMAIN_PROFILES_URL`  | none                                      | Repository from which domain profiles are loaded.                         |

> **Note:** The modeler reads the Camunda endpoint from `VITE_CAMUNDA7_ENDPOINT`. A `VITE_CAMUNDA_ENDPOINT` entry in `.env` has no effect.

### Tokens

| Variable              | Used for                                                                                     |
| --------------------- | -------------------------------------------------------------------------------------------- |
| `VITE_OPENAI_TOKEN`   | AI features that detect or generate a model from a natural language description.           |
| `VITE_MISTRAL_TOKEN`  | The **Explain** button of the Math Mode. It is only read from `.env`.                        |
| `VITE_GITHUB_TOKEN`   | **Upload to GitHub** in the toolbar.                                                         |

### GitHub upload

| Variable                   | Meaning                                       |
| -------------------------- | --------------------------------------------- |
| `VITE_GITHUB_REPO_OWNER`   | Owner (user or organization) of the repository |
| `VITE_GITHUB_REPO_NAME`    | Name of the repository                        |
| `VITE_GITHUB_REPO_BRANCH`  | Branch to which models are uploaded           |

### Features

| Variable                    | Effect                                                                                  |
| --------------------------- | --------------------------------------------------------------------------------------- |
| `VITE_ENABLE_NODE_TESTING`  | `true` shows the **Generate Test Flows** button, which generates erroneous test models. |

### Example

```bash
VITE_LOW_CODE_BACKEND=http://localhost:8000
VITE_QUNICORN=http://localhost:8080
VITE_NISQ_ANALYZER=http://localhost:8098/nisq-analyzer
VITE_CAMUNDA7_ENDPOINT=http://localhost:8090/engine-rest
VITE_PATTERN_ATLAS_UI=http://localhost:1978
VITE_PATTERN_ATLAS_API=http://localhost:1977/patternatlas/patternLanguages/af7780d5-1f97-4536-8da7-4194b093ab1d
VITE_QC_ATLAS=http://localhost:6626
VITE_DOMAIN_PROFILES_URL=https://raw.githubusercontent.com/LEQO-Framework/domain-profiles/main
VITE_GITHUB_REPO_OWNER=
VITE_GITHUB_REPO_NAME=
VITE_GITHUB_REPO_BRANCH=
VITE_GITHUB_TOKEN=
VITE_OPENAI_TOKEN=
VITE_MISTRAL_TOKEN=
VITE_ENABLE_NODE_TESTING=false
```

> **Warning:** `VITE_` variables are included in the JavaScript that the browser downloads. Anyone who can open the modeler can read the tokens. Only use tokens with minimal permissions, and don't commit `.env` files that contain tokens.

## The Configuration dialog

Click the gear icon (**Configuration**) in the toolbar. The dialog has four tabs. Click **Save** to apply the changes.

### Editor

| Setting                              | Effect                                                                                       |
| ------------------------------------ | -------------------------------------------------------------------------------------------- |
| Collaboration Mode, User Name        | Turns on real-time collaboration and sets the name shown to other users.                     |
| Connect dropped nodes to edges       | Dropping a node onto an existing edge inserts it into that connection. On by default.         |
| Connect nodes on the same line       | Automatically connects nodes placed on the same horizontal line. Off by default.              |
| Compact Visualization                | Same as in the [Experience Mode](./experience-mode).                                         |
| Completion Guaranteed                | Same as in the Experience Mode.                                                              |
| Experience Level                     | Explorer or Pioneer, same as in the Experience Mode.                                         |

The two automatic connection settings are stored in the browser and kept after a reload.

### GitHub

**Repository Owner**, **Repository Name**, **Branch** and **Token** for **Upload to GitHub**. They override the `VITE_GITHUB_*` variables.

### Low-Code Endpoints

The endpoints of **Camunda 7**, the **NISQ Analyzer**, **Qunicorn** and the **Low-Code Backend**, plus the **OpenAI** and **Mistral** tokens.

### Pattern Endpoints

The endpoints of the **Pattern Atlas UI**, the **Pattern Atlas API** and the **QC Atlas**.

## Domain profile repository

Domain profiles are loaded from a static repository, for example a GitHub repository, GitHub Pages or any static file server. It contains:

```text
index.json              { "domains": [{ "name", "directory", "versions", "latest" }] }
<directory>/<version>.json   one file per profile version
```

Set the base URL with `VITE_DOMAIN_PROFILES_URL` or enter it when you load profiles in **Manage Domain Profiles**. GitHub repository URLs are converted to raw content URLs automatically, using the `main` branch if no branch is given. There is no default repository.

## Running the services with Docker

`docker-compose.yml` starts the modeler and the services it uses:

| Service           | Port   | Purpose                                         |
| ----------------- | ------ | ----------------------------------------------- |
| `web`             | 4242   | The modeler itself                              |
| `leqo-backend`    | 8000   | LEQO backend that compiles models               |
| `server`, `worker-qunicorn` | 8080 | Qunicorn execution service              |
| `camunda-engine`  | 8090   | Camunda 7 workflow engine                       |
| `backend`         | 1234   | Collaboration server for Collaboration Mode     |
| `api`, `worker`   | 3000   | Generation service with its database and Redis  |

Start everything with:

```bash
docker compose up
```

The modeler is then available at `http://localhost:4242`. The `web` and `api` services read the `.env` file.

> **Note:** The collaboration server address is fixed to `ws://127.0.0.1:1234` in `src/yjs.tsx` and can't be configured with a variable.
