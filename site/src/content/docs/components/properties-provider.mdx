## Overview

The **Properties Panel** allows you to configure the currently selected element or the overall model.

The content of the panel depends on what is selected on the canvas:

* When a **modeling element** is selected, the panel displays the properties available for that element.
* When the **empty canvas** is selected, the panel displays the properties of the overall model.

This allows users to configure both individual modeling elements and model-level settings directly within the editor.

## Element properties

When you select a modeling element on the canvas, the Properties Panel displays the properties associated with that element.

The available properties depend on the selected modeling element. For example, selecting an `Encode Value` element provides access to its encoding-related properties, while selecting a `Measurement` element displays properties related to the measurement configuration.

In addition to the property fields, the panel provides an **explanation of each property**. This helps users understand what a property controls and how it affects the selected element.

The general process is:

1. Select a modeling element on the canvas.
2. The Properties Panel displays the element's available properties.
3. Select or edit a property.
4. Use the provided explanation to understand the purpose of the property.

For an overview of the available modeling elements and their properties, see the [Modeling Language](../modeling-language) documentation.

## Model properties

When you click on an **empty area of the canvas**, no individual modeling element is selected. In this case, the Properties Panel switches to the properties of the overall model.

Model properties configure aspects that apply to the model as a whole rather than to a specific element.

The process is therefore:

1. Click on an empty area of the canvas.
2. The Properties Panel displays the model properties.
3. Configure the required model-level settings.
