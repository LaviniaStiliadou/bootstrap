## Overview

The Experience Mode adapts Qonstruct to your experience with quantum computing. It controls which elements the palette shows, how nodes are displayed, and which additional tools are available.

Open the **Experience Mode** panel by clicking its header in the top-left corner of the canvas. Click the header again to collapse it.

![The Experience Mode panel](../../images/experience_mode.png)

## Settings

| Setting                   | Values                     | Effect                                                                                              |
| ------------------------- | -------------------------- | --------------------------------------------------------------------------------------------------- |
| **Domain Profile**        | None or a loaded profile   | Replaces the palette with the elements of a domain profile.                                          |
| **Experience Level**      | Explorer, Pioneer          | Adapts icons and node display to beginners or advanced users.                                      |
| **Compact Visualization** | On, Off                    | Compresses nodes and switches the palette to the compact element set.                               |
| **Completion Guaranteed** | Yes, No                    | Shows only elements for which the backend has an implementation.                                   |
| **Math Mode**             | On, Off                    | Shows the **Math Mode** tab in the right panel.                                                     |
| **QASM Editor**           | On, Off                    | Shows the **QASM** tab in the right panel.                                                          |
| **Collaboration Mode**    | On, Off, plus a user name  | Lets several users edit the same model at the same time.                                            |

### Experience Level

- **Explorer** is meant for users who are new to quantum computing. The palette uses illustrated icons, and nodes show more explanation, for example a beginner view of gates and qubits.
- **Pioneer** is meant for users with an advanced understanding. The palette uses the standard circuit symbols, and nodes show their full configuration.

When you change the level, Compact Visualization is set to the recommended value:

| Experience Level | Compact Visualization |
| ---------------- | --------------------- |
| Explorer         | Off                   |
| Pioneer          | On                    |

You can still change Compact Visualization afterwards.

### Compact Visualization

Compact Visualization reduces the space nodes take on the canvas. It also selects which variant of an element the palette offers. For example, in compact mode the palette shows a single **Encode Value** element, in which you choose the encoding type. Without compact mode, it shows a separate element for each encoding, such as **Basis Encoding** or **Amplitude Encoding**.

### Completion Guaranteed

With **Yes**, the palette only shows elements for which the backend has a suitable implementation, so every model you build can be compiled. With **No**, the palette also shows elements without this guarantee, such as the classical operators, the Ancilla or Schmidt Decomposition. Some category descriptions change accordingly.

### Domain Profile

A domain profile is a palette tailored to an application domain, with its own elements and their mapping to standard elements. Select **None** to use the standard palette. Profiles are managed with **Manage Domain Profiles** in the toolbar and can be loaded from a profile repository (see [Configuration](./configuration)).

### Math Mode and QASM Editor

These switches show additional tabs in the right panel:

- [Math Mode](./math-mode): the Dirac notation, derivation steps, histogram and Bloch sphere of the circuit.
- [OpenQASM Editor](./openqasm-editor): the OpenQASM code of the model, and conversion of OpenQASM code into a model.

### Collaboration Mode

Collaboration Mode synchronizes the model between several users in real time. Enter the name under which other users see your cursor and changes. The field is only editable while Collaboration Mode is on. Collaboration requires the collaboration backend (see [Configuration](./configuration)).
