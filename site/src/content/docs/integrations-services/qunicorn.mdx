## Qunicorn

Qunicorn is a **unification middleware** for accessing quantum computers through different quantum cloud offerings.

Quantum cloud providers differ in their interfaces, supported programming languages, circuit formats, result formats, hardware, and access models. Qunicorn abstracts these differences and provides a common layer between quantum applications and the underlying quantum cloud infrastructure.

A central feature of Qunicorn is the automatic translation between different quantum circuit and result formats. This allows quantum applications to interact with different quantum cloud offerings without having to be rewritten for every individual provider.

Qunicorn therefore helps reduce dependencies on specific quantum programming languages and cloud providers and provides a more flexible way of working with heterogeneous quantum computing resources.

```text
Quantum Application
        │
        ▼
     Qunicorn
        │
   ┌────┼────┐
   ▼    ▼    ▼
 Cloud  Cloud  Cloud
   A      B      C
   │      │      │
   ▼      ▼      ▼
Quantum Quantum Quantum
Computer Computer Computer
```

The project explores how a middleware architecture can simplify access to quantum computing resources and reduce **vendor lock-in** by separating quantum applications from provider-specific technologies.

## Qunicorn in Qonstruct

Qonstruct uses Qunicorn as the middleware for executing quantum circuits. Once a Qonstruct model has been transformed into an executable quantum circuit, Qunicorn provides the interface between the circuit and the selected quantum cloud offering.

This separates the execution logic of Qonstruct from the provider-specific details of quantum hardware and cloud platforms. Qonstruct can therefore generate and submit quantum circuits through a common middleware layer, while Qunicorn handles the translation and communication required by the respective quantum provider.
